# Janus UI 风格与主题规范

> 文档版本：v0.2  
> 日期：2026-11-20  
> 阶段：M1 应用壳实现与 UI 验证  
> 实现基线：Tauri 2.12.6 + React 19.3.1 + TypeScript 7.0.2 + Vite 8.3.8  
> 运行环境：Windows 10/11 + Microsoft Edge WebView2  
> CSS 兼容目标：WebView2；特性降级基线按 Chromium 105+ 约束  
> Token 源文件：`design/tokens.css`  
> 高保真预览：`design/ui-style-preview.html`

## 1. 产品定位

Janus 是 Windows 桌面端语言学习工作台。第一阶段聚焦英语，后续通过 Language Pack 扩展其他语言。

界面不是课程商城，也不是游戏化打卡面板。它应当像一间安静、精确、可长期使用的语言工作室：

- 用户每天打开后，能立刻知道下一步做什么；
- 学习材料是第一视觉层级，AI 与评分是辅助层；
- 复杂的语音能力通过清晰状态呈现，不制造“黑箱感”；
- 长时间使用不产生视觉疲劳；
- 与太阳系软件系列共享骨架，但拥有独立的 Iris + Brass 识别。

### 1.1 M1 实施状态

本规范中的桌面壳层、主题、布局与基础交互已在真实 Tauri 窗口中实现并验收：

- 1360×820 常规窗口与 1040×700 最小窗口；
- 浅色/深色主题与主题持久化；
- 自定义标题栏、原生拖拽、双击最大化/还原和窗口按钮；
- 232 px 常规侧栏与 72 px 紧凑侧栏；
- 主内容独立滚动、搜索浮层、Toast 与空结果状态；
- 系统不支持 backdrop blur 时的实色降级。

尚未实现、因此仍按“目标规范”执行：

- 单词/句子/听力/朗读的真实学习界面与数据状态；
- 麦克风、录音、流式字幕、波形、打断与发音反馈；
- 组件库全量、全部 DPI 档位与屏幕阅读器矩阵；
- 安装、签名、更新与正式发布相关界面。

## 2. 设计原则

### 2.1 安静的高级感

高级感来自秩序，而不是装饰：

- 大面积暖纸或深墨；
- 少量高对比文字；
- 一个主操作；
- 细边框、低阴影、克制玻璃；
- 不使用营销 Banner、渐变标题、霓虹、玻璃球和装饰性星球。

### 2.2 一个画面一个焦点

每一页只保留一个最高优先级动作：

- 今日学习：继续学习；
- 单词复习：显示答案或下一次；
- 听力：播放；
- 朗读：录音；
- AI 对话：开始/结束对话。

次要动作使用次级按钮、文字按钮或图标按钮，不与主操作争夺颜色。

### 2.3 紫色是动作，不是底色

Janus Iris 仅用于：

- 主按钮；
- 当前导航项；
- 焦点环；
- 进度与活动图；
- 可交互选中态。

建议任意页面中饱和度较高的紫色面积不超过可视面积的 5%–8%。黄铜色面积更小，只用于关键节点、成就、重要数据和语音“正在表达”的瞬间。

### 2.4 纸与墨优先

- 浅色主题以 Warm Paper 为底，Paper White 为卡片；
- 深色主题以 Night Ink 为底，Raised Ink 为卡片；
- 玻璃层只用于标题栏、侧栏与浮层；
- 页面内容卡不使用强烈半透明，避免阅读时受到背景干扰。

### 2.5 4 pt 网格

所有间距、控件高度、图标尺寸与布局节奏必须落在 4 pt 网格上。禁止出现 5、7、10、15、18 等随手数值，除非是字体内在行高或光学对齐修正。

### 3.3 色彩使用规则

1. 正文必须达到 4.5:1；非文字图形和交互边界必须达到 3:1。
2. `--text-3` 只用于不承担关键信息的元数据，不得使用低于 4.5:1 的颜色作为必读正文。
3. 浅色上的强调文字使用 `--accent-ink`，不用 `--accent` 作为小字号正文。
4. 黄铜色在浅色主题中优先作为图形节点；若用于文字，必须使用 `--gold-ink`。
5. 状态色不得只通过颜色表达，必须配合图标、文案或形状。
6. 组件代码不得直接写颜色十六进制值，所有颜色必须引用语义 Token。

## 4. 字体系统

### 4.1 字体栈

- UI 标题：`Segoe UI Variable Display, Segoe UI Variable, Segoe UI, Inter, Microsoft YaHei UI, sans-serif`
- 阅读正文：`Segoe UI Variable Text, Segoe UI, Microsoft YaHei UI, sans-serif`
- 数据与快捷键：`Cascadia Mono, SFMono-Regular, Consolas, monospace`

界面中英文混排时保持同一字号与基线，不因中文自动缩小。

### 4.2 字号层级

| 语义 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| Display | 28–29 / 34 | 600 | 页面主标题、产品名 |
| Title | 20 / 26 | 600 | 模块标题、对话框标题 |
| Heading | 16 / 22 | 600 | 卡片标题、分组标题 |
| Body | 14 / 22 | 400 | 正文、学习材料、描述 |
| Body Strong | 14 / 22 | 500–600 | 强调正文、列表标题 |
| Small | 12 / 18 | 400–500 | 辅助说明、标签、时间 |
| Caption | 11 / 16 | 500 | 元数据、微型标签 |
| Mono | 10–11 / 16 | 500 | 快捷键、编号、计数 |
| Reading | 16–18 / 28 | 400 | 句子拆解、文章阅读、对话字幕 |

### 4.3 排版规则

- 中文正文行高保持 1.6–1.7；
- 英文阅读材料行高保持 1.55–1.75；
- 标题负字距只用于 Display，约为 `-0.02em`；
- 大写英文标签可使用 `0.08em` 字距，正文禁止拉字距；
- 长文本宽度建议控制在 65–80 个西文字符或 35–45 个中文字符；
- 不把小字号紫色文字放在浅紫底上；优先使用中性文字与留白建立层级。

## 5. 布局系统

### 5.1 Windows 应用壳

| 尺寸 | 规范 |
| --- | --- |
| 默认窗口 | `1360 × 820` |
| 最小窗口 | `1040 × 700` |
| 标题栏 | `52 px` |
| 侧栏 | `232 px` |
| 紧凑侧栏 | `72 px` |
| 页面左右边距 | `32 px` |
| 内容最大宽度 | `1120 px` |
| 导航项高度 | `38 px` |
| 常规控件高度 | `36 px` |
| 列表行高 | `44 px` |
| 卡片圆角 | `8 px` |
| 对话框圆角 | `12 px` |
| 图标按钮 | `32 px` |
| 状态胶囊 | `999 px` |

### 5.2 4 pt 间距标尺

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 48 / 64`

- 图标与文字：8 px；
- 按钮内边距：水平 12–16 px，垂直 8–10 px；
- 卡片内边距：16–20 px；
- 卡片间距：12–16 px；
- 页面区块间距：24–32 px；
- 页面顶部到内容：约 28–32 px。

### 5.3 响应式策略

- 窗口宽度 ≥ 1180 px：完整侧栏 232 px，主区 4 列卡片；
- 1040–1179 px：侧栏压缩到 72 px，仅显示图标与提示；主区按 2–4 列自适应；
- 高度不足 760 px：主内容区垂直滚动，标题与侧栏固定，不压缩字体；
- 窗口更窄于 1040 px 不允许：由 Tauri 设置最小尺寸。
- Windows 缩放到 125%–200% 时，先保证文字与控件的可读性，再压缩装饰性内容。
## 6. 材质、圆角与阴影

### 6.1 表面层级

1. 应用背景：`--bg`；
2. 主内容卡片：`--bg-raised` + 1 px `--line`；
3. 浮层：`--surface-glass-strong` + 1 px `--line` + `--shadow-2`；
4. 侧栏与标题栏：`--surface-glass` / `--sidebar` + 20–26 px backdrop blur；
5. 选中态：`--accent-soft` 或 `--accent` 实底。

阴影只表达“浮起”，不用于普通卡片的装饰。普通卡片使用细边框和背景差即可。

### 6.2 玻璃质感

- 只在高处或固定层使用：标题栏、侧栏、菜单、对话框、浮动播放器；
- 背景必须有一定色差，避免玻璃层看起来像灰色脏块；
- 不在正文卡上大面积使用 backdrop blur；
- 关闭 Windows 透明效果、不支持 backdrop blur 或需兼容较低 WebView2 版本时，降级为不透明背景；
- 实现使用 `@supports not ((-webkit-backdrop-filter: blur(1px)) or (backdrop-filter: blur(1px)))` 检测；
- 实色降级值由 `--surface-glass-fallback`、`--surface-glass-strong-fallback` 与 `--sidebar-fallback` 提供，组件不得直接写死浅/深色。

### 6.3 焦点环

- 焦点颜色：浅色 `#6A55C2`，深色 `#9A8CF5`；
- 形式：2 px 外环 + 1 px 透明间隙，外围总视觉宽度约 3 px；
- 键盘焦点必须清晰可见，鼠标点击不应长期留下焦点环；
- 危险按钮的焦点环保持主焦点色，不使用红色焦点环。

## 7. 桌面壳层

### 7.1 标题栏

高度 52 px，包含：

- 左侧：Janus 符号、产品名、当前学习语言（如“英语 · B1”）；
- 中部：本地状态、同步状态或当前学习上下文；
- 右侧：主题切换、搜索、最小化、最大化/还原、关闭。

规则：

- 使用 Tauri 原生 `data-tauri-drag-region="deep"` 处理标题栏拖拽与双击最大化，不叠加自定义 `onMouseDown` 拖拽，避免双重拖拽和事件冲突；
- capability 必须显式包含 `core:window:allow-start-dragging`，否则原生拖拽会触发 ACL 拒绝；
- 最小化、最大化切换、状态读取与关闭由应用内 Rust 命令完成，前端通过类型化封装调用；
- 监控窗口 `resize` 事件并重新读取最大化状态，确保双击标题栏后按钮图标与可访问名称同步；
- Windows 窗口控制按钮使用系统惯例位置；
- 不使用自绘的高饱和标题栏；
- 关闭按钮 hover / active / 对比文字仅使用 `--window-close-hover`、`--window-close-active`、`--window-close-contrast`，不借用主题状态色；
- 标题栏中部内容在窄窗口下优先隐藏，左侧品牌与右侧窗口控制保留。

### 7.2 侧栏

- 导航项高度 38 px，图标 18 px，左内边距 10 px；
- 当前项使用 Iris 实底与反白文字，不额外加左侧竖条；
- 数量徽标使用低饱和填充，不使用黄铜作为计数色；
- 一级分组：学习、资料、设置；
- 底部保留连续学习、用户入口与帮助；
- 折叠时只保留图标，悬浮提示补充名称；
- 键盘支持 `Ctrl+1` 至 `Ctrl+6` 快速切换核心模块，`Ctrl+K` 打开搜索与快速跳转；`Esc` 关闭搜索浮层。

### 7.3 主内容区

- 页面顶部使用简短元信息，如 `THURSDAY · DAY 12`；
- 主标题不超过两行；
- 主标题下方可有 1 行说明，不堆叠营销文案；
- 页面主操作放在主标题或首个学习模块附近；
- 主内容区独立滚动，不滚动整个桌面窗口壳。

## 8. 组件规范

### 8.1 按钮

| 类型 | 视觉 | 用途 |
| --- | --- | --- |
| Primary | `--accent` 底、`--accent-contrast` 文字 | 每屏一个主操作 |
| Secondary | `--bg-raised` 底、`--line-strong` 边框 | 调整计划、查看详情 |
| Ghost | 透明底、`--text-2` 文字 | 取消、次要导航 |
| Danger | `--danger` 底或红色文字 | 删除、重置 |
| Icon | 32 px 方形 | 搜索、播放、设置 |

状态：

- hover：提高填充或边框对比，不改变布局；
- active：缩放 `scale(0.98)` 或降低亮度，持续 100 ms；
- disabled：降低不透明度并移除阴影，保持文字可读；
- loading：保留按钮宽度，显示小型进度指示，防止布局跳动。

### 8.2 表单控件

- 高度 36 px，圆角 8 px；
- 输入框使用 `--bg-raised` 与 `--line`；
- 聚焦时边框变为主色，并显示 3 px 焦点环；
- 错误时使用 `--danger` 文字 + 图标 + 说明，不只变红；
- 占位文字必须达到可读对比度，不能仅作为唯一标签；
- 搜索输入左侧固定 16 px 图标，右侧可放快捷键提示。

### 8.3 卡片

- 背景 `--bg-raised`，边框 1 px `--line`，圆角 8 px；
- 默认无重阴影；
- 卡片内边距 16–20 px；
- 只有主学习卡或 AI 对话卡可以带轻微阴影与主色浅底；
- 不建议卡片内再嵌卡片；需要分组时使用分隔线和间距；
- 卡片整体可点击时，hover 仅改变边框和 1–2 px 抬升，不使用大幅缩放。

### 8.4 列表

- 行高 44 px；
- 左侧为主文字与次级说明，右侧为状态、时间或操作；
- 分隔线使用 `--line`，最后一行不重复外框；
- 行 hover 使用 `--fill-soft`；
- 列表可承载键盘上下移动，Enter 执行主操作；
- 长文本截断时必须有 tooltip 或详情页。

### 8.5 标签与状态

- 状态胶囊高度 20–24 px，字号 10–11 px；
- due / new / live / drill 使用不同文字标签，但底色统一低饱和；
- live 状态使用小圆点 + 文本，不仅用绿色；
- 黄铜胶囊只用于成就或关键提醒；
- 不使用一屏超过 2 个高饱和胶囊。

### 8.6 进度与图表

- 进度环使用主色，中心数字使用主文字；黄铜可标记当前节点；
- 折线图使用主色 2 px 线宽；
- 面积填充透明度不超过 20%；
- 坐标轴与网格使用 `--line`，不使用高对比黑线；
- 关键最新点可用黄铜节点；
- 所有图表需要文本摘要，不能只提供图形；
- 数据为空时显示下一步动作，不显示“暂无数据”孤零零一句。

### 8.7 对话框与浮层

- 圆角 12 px；
- 最大宽度：确认框 420 px，表单框 560 px，学习内容浮层 720 px；
- 标题 20 px，正文 14 px，操作区右对齐；
- 危险操作用红色主按钮，并提供取消；
- 关闭按钮与 Esc 必须可用；
- 焦点进入对话框后被捕获，关闭后回到触发元素。

### 8.8 Toast 与内联反馈

- Toast 用于短暂、非阻塞的结果；
- 学习纠错不使用 Toast，使用内容旁的内联标注；
- AI 服务失败时，给出可理解原因与降级操作；
- 重要结果保留在页面中，不依赖 2 秒后消失的提示。

### 8.9 空态、加载与错误

- 空态：一句状态说明 + 一个明确动作；
- 加载：骨架屏或局部进度，不使用整屏旋转图标；
- 错误：保留用户输入；提供重试、离线继续或改为文字模式；
- AI 等待超过 1.5 秒时展示具体阶段，如“正在识别语音”“正在生成回应”。

## 9. 学习工作台

首页是“今天做什么”的工作台，不是课程列表：

1. 今日目标与连续学习；
2. 今日学习路径：单词 → 听力 → 口语 → AI 对话；
3. 4 个可进入的学习卡片；
4. 本周学习节奏；
5. 正在进入长期记忆的复习队列。

布局原则：

- 今日路径是唯一带主色浅底的展示卡；
- 学习卡片高度统一，但内容可以不同；
- 数据统计放在下半区，占视觉面积不超过 35%；
- 不在首页放入长视频、广告或大量课程封面。

## 10. 语音学习视觉语言

### 10.1 通用结构

语音交互界面由四层组成：

1. 会话上下文：场景、角色、目标句型；
2. 语音状态：当前是听、识别、思考、表达还是纠错；
3. 实时字幕：目标语言原文与可选翻译；
4. 延迟反馈：发音、用词、语法与流利度提示。

波形不是装饰。它必须表示真实输入幅度、播放状态或打断可用性，并在无音频时降级为静态状态图标。

### 10.2 状态机

| 状态 | 主色 | 文案示例 | 视觉 |
| --- | --- | --- | --- |
| Idle | 中性 | 准备好了吗 | 麦克风轮廓 |
| Listening | Iris | 正在听你说话 | 主色环 + 动态输入波形 |
| Recognizing | Iris | 正在识别 | 低幅脉冲 + 字幕“识别中” |
| Thinking | Iris / 中性 | 正在组织回应 | 三点或细环，不使用长时间旋转 |
| Speaking | Brass | AI 正在回应 | 黄铜节点 + 输出波形 + 可打断 |
| Correcting | Warning | 发现 2 处可改进 | 内联标记与短说明 |
| Paused | 中性 | 已暂停 | 恢复按钮 |
| Degraded | Warning | 已切换为文字对话 | 模式标签与重试入口 |
| Error | Danger | 麦克风被占用 | 原因 + 打开设置 |

### 10.3 实时字幕

- AI 与用户均显示说话人标签；
- 当前句以正文色显示，未确认的流式识别使用 `--text-2`；
- 翻译默认折叠或在设置中开启；
- 纠错标记使用下划线和可展开说明，不使用满屏红字；
- 字幕必须支持键盘滚动、复制与屏幕阅读器读取。

### 10.4 发音反馈

- 发音评分必须显示评测维度，如准确度、完整度、流利度、韵律；
- 总分不能脱离原始音频与音素提示独立存在；
- 错误音素使用下划线与对应 IPA 提示；
- 允许用户对照原音、回放自己的录音、再次跟读；
- 低置信度结果显示“建议再读一次”，不直接判定错误；
- 评分色阶：主色表示可继续练习，绿色表示达标，黄铜表示进步节点，橙红色仅用于明确问题。

### 10.5 打断与权限

- AI 播放时可以随时打断；
- 打断按钮在播放和说话状态下始终可访问；
- 首次使用麦克风前说明用途、存储策略和关闭方式；
- 录音默认不持久化；用户主动保存时才进入本地学习记录。

## 11. 动效

### 11.1 节奏

| Token | 时长 | 用途 |
| --- | --- | --- |
| `--dur-press` | 100 ms | 按下反馈 |
| `--dur-fast` | 160 ms | hover、状态切换 |
| `--dur-standard` | 240 ms | 卡片展开、页面过渡 |
| `--dur-panel` | 300 ms | 对话框、浮动播放器 |

缓动：

- 标准：`cubic-bezier(0.32, 0.72, 0, 1)`
- 出现：`cubic-bezier(0.2, 0.8, 0.2, 1)`

### 11.2 规则

- 动画解释状态变化，不制造持续注意力占用；
- 不使用弹跳、抖动、无限呼吸光晕；
- 页面切换使用淡入 + 4–8 px 位移，不整页横滑；
- 学习内容切换优先即时完成，不与用户输入抢节奏；
- 支持 `prefers-reduced-motion`，关闭位移动画与波形自动循环。

## 12. 无障碍与国际化

### 12.1 无障碍

- 目标 WCAG 2.2 AA；
- 所有交互控件可用键盘访问；
- 焦点顺序与视觉顺序一致；
- 语音状态变化通过 `aria-live` 播放，但不重复播报流式字幕的每个词；
- 录音、播放、停止、打断按钮有明确可访问名称；
- 任何颜色状态都有文本或形状补充；
- 支持 200% 系统缩放与 200% 文本放大；
- 不将音高、语速或声音作为唯一反馈通道。

### 12.2 中文与多语言

- UI 语言与学习目标语言是两套独立设置；
- 所有文字容器允许 30% 以上长度增长；
- 阿拉伯语等 RTL 语言在未来必须由布局方向 Token 支持；
- 英文、中文、日文、韩文与 IPA 使用各自的字体回退；
- 不把英文句子的词数、字符数或语序写死为 UI 假设；
- 语音识别、TTS 与评分配置来自当前 Language Pack，而非全局常量。

## 13. Token 与实现规则

1. `design/tokens.css` 是颜色、字体、间距、圆角、动效和布局的唯一来源。
2. 组件只使用语义 Token，不直接使用十六进制色值。
3. 主题切换通过根节点 `data-theme="light|dark"` 完成。
4. 未显式设置主题时，支持跟随系统主题。
5. 深色主题不是简单反色：背景、文字、主色、状态色与阴影均独立配置。
6. 玻璃效果在系统关闭透明效果或不支持 backdrop blur 时必须有实色降级。
7. 任何新增 Token 需要说明语义、浅/深值、对比度与使用边界。
8. UI 预览是设计参考，不是最终组件实现；组件实现后需用真实窗口尺寸回归。
9. 窗口关闭状态色不得复用 `--danger`；必须使用独立 `--window-close-hover`、`--window-close-active` 与 `--window-close-contrast`。
10. 玻璃效果的兼容基线按 WebView2 / Chromium 105+ 管理；不得依赖超出该基线的 CSS 特性而不提供降级。
