# Janus 品牌资产

## 文件

| 文件 | 用途 |
| --- | --- |
| `janus-symbol.svg` | 浅色背景透明符号 |
| `janus-symbol-dark.svg` | 深色背景透明符号 |
| `janus-symbol-mono.svg` | 单色印刷 / 单色界面 |
| `janus-wordmark.svg` | 浅色背景横版字标 |
| `janus-wordmark-dark.svg` | 深色背景横版字标 |
| `janus-mark.svg` | 深色圆角应用图标母版 |
| `janus-app.ico` | Windows 安装器与可执行文件图标 |
| `icons/janus-app-*.png` | 16、24、32、48、64、128、256、512 px 导出 |
| `brand-board.html` | 可编辑品牌板 |
| `brand-board.png` | 品牌板完整交付预览 |

## 规则

- 所有符号使用原始 SVG；不要修改路径、描边宽度、节点位置或几何比例。
- 浅色背景使用 `#6A55C2` 主符号与 `#A87828` 节点。
- 深色背景使用 `#9A8CF5` 主符号与 `#D6B36A` 节点。
- 正式 UI 只引用语义 Token，不直接复制十六进制色值。
- 最小应用图标尺寸为 16 px；低于该尺寸不使用 Logo。
- 不拉伸、旋转、加外框、加阴影底板或使用渐变。

完整规范见 `../../design/logo-design.md`。
