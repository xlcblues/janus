# Janus Logo 设计方案

> 文档版本：v0.2  
> 日期：2026-11-20  
> 阶段：第一阶段 / 品牌与视觉冻结  
> 适用范围：Windows 桌面端、应用图标、安装器、官网与产品内品牌露出

## 1. 设计任务

Janus 是太阳系软件系列中的语言学习产品。第一阶段先完成品牌、UI 与桌面壳工程基线；完整学习闭环从 M2 开始，不以静态评分或模拟对话填充功能。

Logo 需要同时满足五个条件：

1. 与名称 **Janus** 的神话语义发生直接联系；
2. 保持极简，可缩小到 16 px 的 Windows 应用图标；
3. 与 Mars、Ceres、Neptune、Titan、Miranda、Europa 共享“单色几何 + 节点 + 纸墨底色”的系列语言；
4. 不复制任一既有项目图形，只继承共同视觉语法；
5. 能推导出一套克制、可长期使用的高级 UI 主题。

## 2. 命名与概念

### 2.1 Janus 的语义

Janus 是罗马神话中的门神，也是开端、过渡、结束与边界的守护者。Janus 常被描述为“双面”，但本 Logo 不采用字面双脸，也不使用人物、眼睛或星球插画。

语言学习本身就是一次跨越边界：

- 从听懂到说出口；
- 从母语映射到目标语言；
- 从知识识别到真实交流；
- 从单次练习到长期记忆；
- 从学习者与 AI 的单向问答，到两个角色之间的双向表达。

### 2.2 核心母题：双面之门（Janus Gate）

Logo 由两条镜像的 J 形拱线组成：

- 它们合在一起形成一扇开放的门；
- 每一条线同时是 J 字母、半边脸与一个对话方向；
- 中间的负空间保持开放，表示语言必须被“穿过”，而不是被观看；
- 顶部交会处的黄铜圆点是一个转换节点，表示理解发生的“此刻”；
- 不封闭门洞，因为学习永远保留继续输入与继续表达的空间。

### 2.3 三层含义

| 层级 | 含义 | 图形对应 |
| --- | --- | --- |
| 双面 | 两种视角、两个对话者 | 两条镜像 J 形拱线 |
| 双向 | 输入与输出、听与说 | 开放门洞与相互支撑的曲线 |
| 此刻 | 一次理解或表达发生 | 顶端黄铜节点 |

## 3. 几何构成

### 3.1 母版参数

- 画布：`512 × 512`
- 坐标原点：左上角
- 左拱路径：`M152 386V252c0-77 50-125 90-126`
- 右拱路径：`M360 386V252c0-77-50-125-90-126`
- 描边宽度：`34`
- 描边端点：圆形，半径等于描边宽度的一半
- 节点圆心：`(256, 126)`
- 节点半径：`19`
- 图形视觉外框约为 `242 × 296`，在画布中垂直略高于水平，保持轻微“门”的纵向感

### 3.2 几何原则

1. 两条曲线必须严格镜像，不能一条更粗、一条更短。
2. 顶部节点必须位于两段曲线共同指向的交会轴线上。
3. 门洞保持开放，不与底部横线连接。
4. 不使用渐变、重描边、多层轮廓或立体材质。
5. 图形只能等比缩放，不能为了适配画布而拉伸。

### 3.3 安全区与留白

- 独立符号的安全区按图形视觉外框计算，四周至少保留 `64 px`（512 画布约 12.5%）。
- 与文字并排时，符号到字标的最小距离为符号宽度的 `0.25 倍`。
- 不把 Logo 贴近窗口边缘、卡片边缘或裁切容器边缘。
- 应用图标内不使用额外底板；母版 `janus-mark.svg` 的深墨圆角矩形本身就是图标底板。

## 4. 色彩

### 4.1 Logo 专用色

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| Janus Iris | `#6A55C2` | 浅色背景上的主符号 |
| Iris Light | `#9A8CF5` | 深色背景上的主符号 |
| Brass Mark | `#A87828` | 浅色符号节点 |
| Brass Light | `#D6B36A` | 深色符号节点 |
| Night Ink | `#12111A` | 应用图标底板、深色背景 |
| Warm Paper | `#F4F1EA` | 浅色品牌背景 |

浅色界面中的小字号文字强调应使用 `#58439F`（Iris Deep），不要用低对比度的浅紫。Trial Brass `#B48736` 是 UI 中的关键节点与成就色，不作为浅色背景上的正文小字色。

### 4.2 对比度

| 组合 | 对比度 | 判断 |
| --- | ---: | --- |
| `#6A55C2` / `#F4F1EA` | 5.04:1 | 通过普通文字与图形 |
| `#58439F` / `#F4F1EA` | 6.85:1 | 通过小字号强调与正文 |
| `#1B1924` / `#F4F1EA` | 15.37:1 | 通过正文 |
| `#676273` / `#F4F1EA` | 5.21:1 | 通过次级正文 |
| `#6F6979` / `#F4F1EA` | 4.69:1 | 通过三级信息文字 |
| `#9A8CF5` / `#12111A` | 6.64:1 | 通过深色界面主操作与符号 |
| `#D6B36A` / `#12111A` | 9.38:1 | 通过深色界面节点与文字 |
| `#A87828` / `#F4F1EA` | 3.46:1 | 通过非文字图形 3:1 门槛 |

## 5. 与太阳系软件系列的关系

### 5.1 共同语言

- 使用单色几何主形；
- 保留一个具有轨道或坐标意味的节点；
- 深墨与暖纸作为大面积基础色；
- 少量玻璃质感，不做霓虹与高饱和装饰；
- Windows 桌面壳层、标题栏、侧栏与内容区保持系列骨架；
- 每个项目只拥有一个独立主色，不争夺同一视觉语义。

### 5.2 Janus 的独立识别

Janus 用 **Iris 紫**表示语言转换与学习动作，用 **黄铜节点**表示一个表达被理解、被校准或被记住的瞬间。紫色与黄铜不会同时大面积出现：

- 紫色是动作、选中、焦点与进度；
- 黄铜是成就、关键节点、少量数据与“此刻”；
- 纸与墨是背景和结构。

### 5.3 禁止的“系列化”误读

- 不复制 Mars 的锈红、Ceres 的森绿、Neptune 的海蓝或 Europa 的冰青作为 Janus 主色；
- 不把既有项目 Logo 中的轨道、圆环或笔画直接套用；
- 不为了“看起来像同系列”而加入无意义的轨道、星球或渐变。
## 6. 字标与组合

### 6.1 字标规范

- 字体：Segoe UI Variable Display Semibold / 600
- 字距：0
- 颜色：浅色背景使用 Night Ink，深色背景使用 Warm Paper
- 不把“Janus”做成装饰字体，不使用斜体、手写体或过度字距
- 字标只用于品牌露出；应用内标题与菜单仍使用常规 UI 字体层级

### 6.2 横版组合

`janus-wordmark.svg` 使用符号 + “Janus”横排：

- 画布：`640 × 160`
- 符号视觉高度约 96 px
- 字标字号：`62 px`
- 前景色：浅色版 Night Ink，深色版 Warm Paper
- 仅用于标题栏、安装器、官网页眉等横向空间充足的位置
- 宽度低于 112 px 时不使用横版字标，改用符号

## 7. 应用图标规范

### 7.1 Windows 图标

应用图标母版为 `janus-mark.svg`：

- 512 × 512 画布；
- 深墨 `#12111A` 圆角矩形；
- 圆角半径 112，约为边长的 22%；
- 中央使用深色主题符号；
- 图形与图标边缘保持足够安全区；
- 不添加外部投影、光晕、内描边或水印。

### 7.2 小尺寸验收

- 16 px：门形仍能辨认，左右两道拱线不粘连；
- 24 px：黄铜节点至少呈现为一个清晰的亮点；
- 32 px：轮廓、节点与圆角都可读；
- 48 px 及以上：允许显示完整节点与品牌色细节；
- 任何尺寸都不允许用字标替代符号。

## 9. 使用边界

### 正确

- 使用 SVG 母版等比缩放；
- 浅色背景使用 Iris，深色背景使用 Iris Light；
- 节点始终保留在拱门顶端交点；
- 需要强调时只提高对比度，不改变形状；
- 在单色场景中使用 `janus-symbol-mono.svg`；
- 在 Windows 任务栏、开始菜单、安装器中使用 `.ico` 或对应 PNG。

### 避免

- 不拉伸、旋转、透视、倾斜或镜像；
- 不添加外框、阴影底板、浮雕、发光或渐变；
- 不使用星球纹理、眼睛、面具或字面双脸；
- 不额外复制节点，不把节点改成眼睛；
- 不在低对比度背景上使用同色 Logo；
- 不把 Logo 当作页面主视觉装饰重复铺满界面。

## 10. 无障碍要求

- 作为品牌图形时，为 SVG 提供可访问名称；装饰性复用时标记为空。
- Logo 不承担唯一状态信息；产品中的紫色焦点、黄铜节点与状态色必须同时有文字或图形语义。
- 小字号文字不使用 `#B48736`、`#6A55C2` 以外的低对比度变体作为正文颜色。
- 色盲用户必须能通过形状、文字与位置区分主要状态，不能只依赖 Iris 与 Brass 的色差。
